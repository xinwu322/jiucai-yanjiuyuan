# 韭菜研究院 · 桌面行情终端 v1.1

Windows 单文件行情终端，直连通达信行情服务器，全市场 5,200+ 只 A 股，**无需安装、无需 Python、解压即用**。

---

## 一、运行要求

| 项目 | 说明 |
|---|---|
| 系统 | Windows 10 / 11（64 位） |
| 其他 | 无需 Python、无需运行库、无需配置 |
| 网络 | 需能访问通达信行情服务器（TCP 7709） |
| 磁盘 | 约 40 MB |

双击 `韭菜研究院.exe` 启动；首次运行若提示「Windows 已保护你的电脑」，点「更多信息 → 仍要运行」。

---

## 二、界面结构

左侧竖向导航，五个工作区：

| 模块 | 作用 |
|---|---|
| 行情 | 全市场列表 + 个股详情（本文重点） |
| 选股 | 多条件实时筛选，结果可双击跳到行情 |
| 提醒 | 价格/涨幅/量比事件监听，触发即弹窗 |
| 交易 | 模拟盘下单，验证风控流程（不接真实柜台） |
| 复盘 | 示例复盘观点卡 + 交易体系 DSL（可替换为自己的解析结果） |

顶部：连接状态、毫秒延迟、全局搜索框、时钟。底部：量比预热进度、全市场涨跌家数。

## 三、行情工作区

### 3.1 筛选

- **市场**：全部 / 自选股 / 沪市 / 深市 / 北交所
- **板块**：沪市主板 / 深市主板 / 创业板 / 科创板 / 北交所
- **行业**：按细分行业下拉选择（数据来自新浪行业分类，覆盖约 3,000 只；未收录的显示「—」）

### 3.2 列表字段

名称/代码、现价、涨跌幅、量比、成交量（万手）、**缩略分时**、**板块**、**细分行业**。

点表头排序；点击行切换右侧详情。

### 3.3 自选股分组

切到「自选股」后，筛选行出现「分组」区域：

- 「+ 新建分组」创建分类（如 半导体、电力）
- 点击分组名只看该组
- 右键股票 →「添加至自选股」→ 选分组（或新建）
- 分组保存在 `%APPDATA%\JiuYanTerminal\watch_groups.json`

### 3.4 右键菜单

| 菜单项 | 行为 |
|---|---|
| 添加至自选股 → 分组 | 加入指定分组 |
| 展示该板块内股票 | 把「板块」筛选切到该股所属板块 |
| 展示该行业内股票 | 把「行业」筛选切到该股所属行业 |
| 多股同列 | 2×2 迷你走势（自选前 4 只，含当前选中） |
| 复制代码 | 复制到剪贴板 |

### 3.5 全局搜索

支持 **代码 / 名称 / 拼音首字母**（如 `GZMT` → 贵州茅台）。

- 输入即实时过滤当前列表，右上角显示命中数量
- 回车直接跳到第一只命中股票的详情
- 切换市场/板块/行业时，搜索条件继续生效，不会丢失

### 3.6 详情区

- **周期**：分时 / 30分钟 / 日线 / 季线 / 年线
- **日数**（仅分时）：1 ~ 10 日；多日时按各日昨收换算成百分比坐标，并保留各自成交量
- **复权**：不复权 / 前复权 / 后复权（基于通达信 XDXR 除权除息数据）
- **主图指标**：无 / BOLL / 均线系统 / 自定义
- **副图数量**：0 ~ 3，分别指定副图 1/2/3 的指标
- **公式管理器**：查看内置与自定义公式、导入 `.txt`、删除、语法校验

### 3.7 K 线操作

- **Ctrl + 滚轮**：缩放（30 根 ~ 全部历史）
- **滚轮**：左右平移
- **按住拖动**：平移
- **双击**：复位到最近 240 根
- 鼠标悬停：主图显示开高低收/涨跌/成交量，副图图例显示**当前 K 线**各指标数值

30 分钟至年线均为**上市以来全部 K 线**（自动翻页拉取，单只最多 24,000 根）。

## 四、通达信指标公式

**赋值与输出**

```
VAR:=EXPR;            中间变量
VAR:EXPR,COLORRED;    输出画线
```

**行情变量**：`O/OPEN`、`H/HIGH`、`L/LOW`、`C/CLOSE`、`V/VOL`、`A/AMOUNT`，支持中文变量名（如 `量比:VOL/MA(VOL,5);`）

**函数**：`MA EMA SMA DMA WMA REF HHV LLV SUM STD COUNT EVERY EXIST BARSLAST IF CROSS BETWEEN UPNDAY DOWNNDAY ABS MAX MIN SQRT POW LOG INTPART MOD SIGN CONST`

**运算符**：`+ - * / > < >= <= = <> AND OR NOT ()`；`{ }` 为注释。

**修饰**：`COLORRED COLORGREEN COLORBLUE COLORYELLOW COLORGRAY ...`；`COLORSTICK` 画柱状（MACD 用）。

`STICKLINE`/`DRAWTEXT` 等纯绘图语句会被跳过，不影响计算；不支持的函数会明确报错。

`formulas/` 目录附 6 个可直接导入的示例。

## 五、数据源

- 通达信行情服务器（TCP 7709），启动时对 100+ 台测速择优
- 快照含现价/昨收/开高低/成交量/成交额/五档；K 线与分时同源
- **兼容处理**：新版服务器收到旧客户端身份包会切换响应编码，程序跳过该握手包
- 分时走 `get_history_minute_time_data` 按交易日拉取，收盘后可看当日完整分时
- 量比 = 当日累计量 ÷（5 日均量 × 已开市比例），5 日均量后台预热（约 2 分钟）

## 六、常见问题

**连接失败**：公司网络可能封 7709 端口，换网络重试。

**量比显示 --**：预热未完成，看底部进度。

**行业显示 —**：该股不在行业分类库中（约覆盖 3,000 只）。

**北交所列表不全**：标准行情接口不返回北交所代码表，程序内置 920 号段快照引导。

**杀毒误报**：PyInstaller 单文件常见误判，可加信任或用 `source/` 运行。

**从源码运行（macOS/Linux）**
```bash
pip install -r requirements.txt pypinyin
python app.py
```

## 八、已知限制

1. Level-1 行情（3 秒快照），全市场一轮约 1.5–2.5 秒，列表实际 3 秒刷新
2. 行业分类覆盖约 3,000 只（新浪行业口径），未覆盖显示「—」
3. 30 分钟线历史深度取决于服务器，通常可回溯数年
4. 不含财务数据、公告、龙虎榜；交易为模拟盘
